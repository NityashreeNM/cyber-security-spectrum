Networking for Cybersecurity

Welcome to the Networking section of Cyber Security Spectrum by Nityashree.

A strong understanding of computer networking is essential for cybersecurity engineering, ethical hacking, network defense, IoT security, and OT security.

1. Networking Fundamentals

- What is a computer network?
- LAN, WAN, MAN, and PAN
- Network topologies
- Client-server and peer-to-peer networks
- Network devices: Switch, Router, Hub, Bridge, Gateway
- MAC addresses and IP addresses
- Ports and protocols

2. OSI Model

Understand the seven layers of the OSI model:

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

Learn how data moves through each layer and how attacks can affect different layers.

3. TCP/IP Model

- Network Access Layer
- Internet Layer
- Transport Layer
- Application Layer

Important protocols:

- TCP
- UDP
- IP
- ICMP
- ARP
- DNS
- DHCP
- HTTP and HTTPS
- SSH
- FTP

4. IP Addressing and Subnetting

- IPv4 and IPv6
- Public and private IP addresses
- Static and dynamic IP addresses
- Subnet masks
- CIDR notation
- Subnetting calculations
- Default gateway
- Network address and broadcast address
- NAT

5. Routing and Switching

- Routing fundamentals
- Static and dynamic routing

- Default routes

- STP fundamentals
- Network segmentation

6. Network Security

- Firewalls
- IDS and IPS

- Network segmentation

7. Network Analysis Tools

- Wireshark
- tcpdump

- nslookup / dig

8. Practical Networking Labs

Future labs will include:

- Build a small virtual network
- Configure IP addresses
- Practice subnetting
- Analyze packets using Wireshark
- Explore TCP and UDP traffic
- Study DNS and DHCP
- Configure routing
- Understand firewall rules
- Detect suspicious network activity

9. Cybersecurity Applications

Networking knowledge supports:

- Network penetration testing
- Intrusion detection
- Incident response
- Digital forensics
- Cloud security
- IoT security
- OT and industrial network security
- Security architecture

Learning Goal

Build strong networking fundamentals and develop the ability to understand, analyze, secure, and troubleshoot computer networks.
